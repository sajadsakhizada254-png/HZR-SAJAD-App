# HZR-SAJAD-App
🎵 HZR TikTok

HZR TikTok is a project for exploring TikTok account information and reporting inappropriate accounts through authorized methods.

✨ Features

- 🔎 Enter a TikTok username
- 📊 Display follower statistics when authorized API access is available
- 🛡️ Keep track of reported accounts
- 📱 Mobile-friendly design
- 🌐 Built for future development

🔐 Privacy and Security

- Never share passwords or access tokens publicly.
- Use official TikTok APIs and permissions.
- Account reports and moderation actions must follow TikTok's rules and authorized access.
